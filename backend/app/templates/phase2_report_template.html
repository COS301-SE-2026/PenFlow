Assessment Scope & Methodology

The assessment targeted the verified domain {{target_domain}} and externally reachable infrastructure associated with it.

Assessment Area Purpose
Target Resolution Identify externally reachable IP addresses associated with the verified domain.
Service Discovery Identify reachable network ports, protocols, services, products, and observable version information.
HTTP Security Inspect HTTP endpoints and relevant security header configuration.
TLS Inspection Inspect TLS-enabled endpoints and certificate characteristics.
Technology Fingerprints Identify externally observable platforms, servers, frameworks, and software components.
Vulnerability Correlation Correlate sufficiently identified software versions with known vulnerability information.
External Intelligence Supplement active observations with DNS, certificate transparency, infrastructure, and branch intelligence.
